# Governance Metrics

[Governance Entry 001](https://github.com/postfiatorg/postfiatorg.github.io/blob/feat/governance-section/content/governance/2026-11-09-network-priorities.md) gates token generation on measured demand. This page is the single place for those measurements: conversion, product and financial. Every number links to where it comes from. A metric without a feed says **Not connected**; this page never fills a gap with an estimate.

Task Node figures are recomputed from the public Task Node API each time the site is built. The other figures are maintained in [`data/governance_metrics.yaml`](https://github.com/postfiatorg/postfiatorg.github.io/blob/main/data/governance_metrics.yaml) and carry the date they were measured.
