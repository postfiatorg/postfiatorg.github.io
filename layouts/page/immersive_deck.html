The financial product

What is a NAVCoin?

A private token tied to a defined portfolio. Its price follows the portfolio’s net asset value rather than a fixed currency peg.

  1. 1AssetsPortfolio holdings
  2. 2Reserve recordEvidence and sources
  3. 3NAVNet asset value
  4. 4IssueCreate matching units
  5. 5Private exchangeMove value discreetly
  6. 6RedeemReturn units for value
What “private” means

Transaction details are revealed only to the people and systems allowed by the product rules. Operators still retain the information required to check and run the product.

What the proof actually answers

Four questions.
Four visible answers.

01

Which assets count?

The product names the reserve assets and the rule for counting them.

02

Who supplied the data?

Every reserve, custody, and price source has an identity and a role.

03

How many units may exist?

Issuance is bounded by the recorded reserve and valuation rules.

04

How does redemption work?

The product defines the holder’s path back to the underlying value.

Fiat-backed tokens showed how large a market can form around issuer reserves and issuer trust. NAVCoins ask how much of the reserve, valuation, supply, exchange, and redemption process can become directly checkable.

The proof checks declared data and rules. Reviewers still examine asset quality, data origin, custody, legal rights, and recovery procedures.

Distributed agreement

Cobalt: agreement without one permanent authority.

Each validator chooses whom it trusts. Cobalt uses enough overlap among those choices to help honest validators reach the same result.

ABCDEF AGREEMENT
Linkedness enough overlap to stay connectedReliable broadcast receive the same proposalBinary agreement settle on the same yes-or-no result
Current implementation boundary

The Rust workspace contains Cobalt agreement machinery and transition tests. Active registry changes still use signatures under the current authorization rules.
