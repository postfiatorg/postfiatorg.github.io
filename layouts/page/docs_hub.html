Compiled directly from postfiatl1v2.

Rather than maintaining a copy that quietly drifts behind the code, postfiat.org/docs/l1/ is generated automatically from postfiatorg/postfiatl1v2 using its own mkdocs.yml, strict link validation, and redaction policy on every site build.

Prefer reading offline or reviewing a branch locally? Three commands build and serve the exact same browsable site on your machine.

Open /docs/l1/ → mkdocs.yml ↗ llms.txt
Run L1 Docs Locally 
git clone https://github.com/postfiatorg/postfiatl1v2.git
cd postfiatl1v2
python3 -m pip install --require-hashes -r requirements-docs.txt
scripts/docs-site-build
scripts/docs-site-serve --host 127.0.0.1 --port 8088
