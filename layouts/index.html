What it does

Four functions. One ledger.

Post Fiat is a settlement layer for financial exposure, not for coffee. Everything it does serves one loop: represent value precisely, move it privately, keep the base money hard, and point collective intelligence at the result.

01

Represent portfolios trustlessly

A NAVCoin is a floating-value unit. The ledger issues it only against a finalized, proven net asset value: reserves, supply and methodology each open to inspection.

02

Swap into them privately

Asset-Orchard settles both legs of an exchange in one atomic, shielded transition. Per-asset conservation is enforced inside the proof; positions stay private.

03

Maintain a fixed supply

Native PFT has a fixed genesis supply. Every fee burns. There is no validator subsidy and no protocol treasury to mint from.

04

Run an intelligence network

Task Node routes work to pseudonymous contributors and their agents, verifies the evidence, and pays for useful output: a community intelligence layer.

Architecture

The best of XRP, evolved for on-chain capital markets.

The chain keeps the XRP category: known validators, deterministic finality, a fixed-supply native asset, fee burn, no validator subsidy. It changes what XRP left unsolved.

Demonstrated

Value that is proven, not typed in.

NAV is the output of a checked computation. A reserve proof runs in a zkVM, is verified as consensus work, and only then can units be created or retired. If the reserves fall, the NAV falls. It is not a stablecoin and does not pretend to be one.

A666 opened at NAV $1.000000 against $31,386.19 of verified net assets, with a 20 m 12 s Ethereum mainnet round trip. Economics of the NAVCoin →

Demonstrated · devnet

A $10 million order need not cross a $2 million public pool.

Asset-Orchard extends Zcash Orchard to typed assets. A swap spends two notes and creates two under one Halo2 proof, with asset tags bound inside the commitments so one asset's surplus can never pay another's deficit.

Controlled pfUSDC → pNOK swap, 1 Aug 2026: one transition, 5.78 s to prove, 66 ms to verify. Batch matcher still proposed. Read the run →

Implemented · testnet

Post-quantum signatures from genesis.

Accounts and validators sign with ML-DSA-65, the NIST FIPS 204 lattice standard, with domain-separated contexts for transactions, block certificates, bridge witnesses and admissions. The pfUSDC bridge proves that post-quantum finality inside a succinct proof.

Scope stated plainly: the shielded stack (RedPallas, Halo2 over Pasta) remains classical. pfUSDC bridge →

Demonstrated · devnet

Old rules judge new rules.

Cobalt, the protocol Ripple published in 2018 and never shipped, makes validator trust protocol state. Every change to who validates is a typed object, ratified by a quorum of the current registry before it takes effect. An AI model may read admission packets; it never decides.

Six adversarial experiments on the controlled devnet: five-of-six ratifies, four-of-six fails. Cobalt evaluation →

Protocol rule

Hard money underneath risk assets.

Native PFT is fixed at genesis. Fees burn, so supply can only fall. No validator reward exists: a subsidized validator class is exactly the constituency a settlement ledger should decline to create. Zero issuance means zero protocol treasury.
